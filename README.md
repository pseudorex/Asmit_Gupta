# Asmit Gupta | Backend Systems Engineer Portfolio

A modern, highly-interactive personal portfolio website showcasing my backend engineering skills, work experience, and core project case studies. Built using Vite + React, Tailwind CSS, and Framer Motion.

## 🚀 Features
- **Dynamic Case Studies** – Interactive project breakdown panels featuring quantitative stats cards and responsive performance results tables (Locust/K6).
- **Responsive Layout** – Optimized for seamless browsing across mobile, tablet, and desktop devices.
- **Skills Grid** – Custom-themed SVG icons for backend development tools, including FastAPI, SQLAlchemy, Redis, Docker, and WebSockets.
- **Dynamic Logo & Favicon** – Vector-based "AG" monogram favicon that automatically detects and adapts its colors to the user's light/dark browser theme.
- **Smooth Animations** – Native micro-interactions and scroll-triggered animations powered by Framer Motion.

## 🛠️ Tech Stack
- **Frontend Core:** React.js 19, Vite
- **Styling:** Tailwind CSS (v3)
- **Animations:** Framer Motion
- **Icons:** React Icons (Tabler, Feather, FontAwesome, Simple Icons)

## 📦 Installation & Setup

1. **Clone the repository:**
   ```sh
   git clone https://github.com/pseudorex/Asmit_Gupta.git
   ```
2. **Navigate to the project directory:**
   ```sh
   cd Asmit_Gupta
   ```
3. **Install dependencies:**
   ```sh
   npm install
   ```
4. **Start the local development server:**
   ```sh
   npm run dev
   ```
   The app will run locally at `http://localhost:5173/`.
